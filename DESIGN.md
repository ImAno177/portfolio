# Cat Room Visual System

The interface uses a restrained night-blue, cream, gold, mint, coral, and sky palette with hard pixel edges, monospace metadata, and large editorial headings. The room is the first visual anchor: floor-to-ceiling glass, sky, covered balcony, plants, desk, sofa, shelf, board, terminal, and six cats.

Interaction remains legible without game knowledge:

- header links and page sections expose the complete portfolio;
- room hotspots open the same information in dialogs;
- cat controls are regular DOM buttons;
- the CSS room fallback remains visible until Phaser is ready;
- reduced-motion and hidden-tab handling pause autonomous movement.

See `SPEC.md` for the complete content, accessibility, simulation, and deployment requirements.
