# Asset provenance

The implementation audits the repository-supplied `assets/` directory first. Production browser files are copied into `public/assets/`; editable Aseprite/PSD files remain source-only.

## CraftPix sky backgrounds

- Source: [CraftPix freebies](https://craftpix.net/freebies/)
- Terms: [CraftPix file licenses](https://craftpix.net/file-licenses/)
- Local source: `assets/New free backgrounds part1/`
- Usage: local sky state backgrounds and layer references inside the portfolio room.
- License reading: freebie resources may be used and modified inside personal or commercial projects; standalone redistribution of the art files is prohibited. Attribution is not required, but the source is recorded here.

## Cat sprites and top-down interior atlases

- Local sources: `assets/Free pack/` and `assets/Top-Down_Retro_Interior/`
- Current provenance: user-supplied archive; no original creator/license file was included.
- Usage: cat sprite variants, interior atlas references, and the visible asset shelf.
- Release note: the manifest intentionally marks these packs as `unverified user-supplied asset`. Confirm original rights before treating the public deployment as a commercial redistribution.

The site does not download assets from marketplaces at runtime.
